# Assess: read the intent before running SCAMPER

SCAMPER transforms whatever you point it at. Point it at the wrong thing (change the layout the user loved, or keep the layout they wanted gone) and every idea misses. Assessing means reading the request well enough to know **what to transform and what to leave alone**. The output is one visible line the user can correct in a word. Never a questionnaire.

## 1. Goal: the job underneath

Look past the *form* of the request to the job it has to do:

| They asked for | The job underneath |
|---|---|
| "An infographic about sleep" | Show tired parents the three habits that fix most bad nights, in a form they'll save |
| "Make our menu descriptions less boring" | Make a hungry customer choose this dish over the one next to it |
| "Refresh the gym's welcome email" | Get new members to come back a second time in their first week |

The goal decides which SCAMPER ideas are worth keeping and which draft to recommend.

## 2. Clarity: go, assume, or ask

Check five things: **goal, audience, starting point, output (format and size), constraints.**

| Situation | Action |
|---|---|
| All known, or easy to infer | **Go.** State your read in the Assess line. |
| A missing detail you can default (size, tone, platform) | **Assume and say so** in the Assess line: "assuming LinkedIn 1080×1350". |
| Something **critical** missing: no subject, conflicting goals, no idea what "good" means | **Ask first**, then stop. |

**The ask test:** would the answer *substantially* change the output, and is there no sensible default? Only then ask.

**How to ask:**
- 1–3 questions in one batch;
- multiple choice where possible, with a recommended default ("1a, 2a" answers in seconds);
- use a question tool if one exists, otherwise plain text;
- never ask one question per turn.

| Request | Do |
|---|---|
| "Repurpose this checklist post for 'How to prepare for a job interview'" + image | Go |
| "Write 3 subject lines for our spring sale email" | Go; assume the brand voice and say so |
| "Help our brand stand out" | Ask: which piece (logo, website, social, packaging)? Stand out to whom, and against which competitors? |
| "Design something for the launch" | Ask: what is launching, in what format, for which channel? |

## 3. Keep / Change

A request keeps some dimensions and changes others. Only the **Change** dimensions get SCAMPER. Anything the request doesn't mention defaults to **Keep**, because the user chose the source for a reason.

| Dimension | Example of a request that changes it |
|---|---|
| **Message** (what it says) | "Use this layout for a new topic" |
| **Format / medium** | "Turn this article into a carousel" |
| **Layout / structure** | "Design something like this reference" |
| **Audience** | "Make a beginner version" |
| **Purpose / goal** | "Turn the case study into a sales email" |
| **Channel / platform** | "Resize for Stories", "cut 16:9 to 9:16" |
| **Length / scale** | "Shrink to a thread", "expand into an article" |
| **Style / brand** | "In our brand colours", "less formal" |

### Phrasing cues for "repurpose" and friends

Check the noun next to the verb:

- "Repurpose / reuse ***this design / template / layout*** for X" → **template reuse.** Keep layout and style; change the message.
- "Repurpose / turn ***this post / article / webinar*** into…", "make a carousel from this", "for social" → **reformat.** Keep the message; change the format. Deliver **one** format: the one named, or the best fit for the audience, stated in the Assess line. Don't produce several formats.
- "Design X… ***reference*** attached", "something ***like this***", "***inspired by***" → **from a reference.** Keep the core idea; change layout and message. The verb "design" plus the word "reference" means the user expects visual freedom.
- Cues in conflict (e.g. "see attached reference to repurpose") → choose the reading that the main verb supports ("design" → from a reference), and offer the flip in the Assess line.

## 4. Effort

| Level | When | What it means |
|---|---|---|
| **Light** | One-liners, captions, "a few angles", "quick", "rough" | Quick pass: 5–6 options, one pick, under 300 words |
| **Standard** (default) | Everything else | Assess and map, three drafts, close |

## 5. The Assess line

One line, at the very top:

> **Read as:** <full session · template reuse · reformat · from a reference · focused lens · quick pass · custom> · **Goal:** … · **Keep:** … · **Change:** … · **Effort:** light/standard · *Say "…" to adjust.*

The closing hint names the one or two flips most likely to matter ("keep layout", "carousel instead"). A wrong read then costs the user one word, not a round.
