# The three presets

"Repurpose" means different things depending on what stays fixed. The Assess line's **Keep / Change** handles any combination (see `assess.md`). These three combinations are common enough to have a set recipe.

| Preset | Keep | Change | Phrasing cues |
|---|---|---|---|
| **Template reuse** | Layout, style | Message (topic) | "repurpose / reuse *this design / template / layout* for [topic]" |
| **Reformat** | Message | Format, channel, length | "turn *this post / article / webinar* into…", "repurpose *this blog* for LinkedIn" |
| **From a reference** | Core idea or mechanism | Layout, message, often style | "design X, see reference", "something like this", "inspired by" |

---

## Template reuse

The user picked the source for its structure. Keep the skeleton, and give every part a new meaning that is just as strong.

### 1. Take a slot inventory

List every slot before writing anything. Example: a "Marketing Funnel" infographic.

| Slot | Job it does | Limit | Carries a metaphor? |
|---|---|---|---|
| Title | Names the topic | ~3–5 words, 1–2 lines | No |
| Tagline | One-line promise | ~8 words | No |
| Funnel (3 bands) | Stages, from wide to narrow | 3 × 1–2 words | Yes: *narrows* |
| Stage metric | The number that matters at each stage | ~10 characters | Yes: *shrinks* |
| Tactic list per stage | What to do | 3 bullets, ≤6 words | No |
| Side arrow | "Drop-off" | 2–3 words | Yes: loss |
| Tip box | One takeaway | ≤20 words | No |
| Footer | Creator CTA | 1 line | No |

Slots that carry a metaphor are where layout decisions happen.

### 2. The content moves that work best

- **S: re-map each metaphor slot to a measure the new topic really has.**
- **R: invert a metaphor when the new topic runs the other way.** A narrowing funnel can become one that *widens* when the new topic is about growth.
- **C: add one demonstrating element,** so the design proves its own point.
- **E: drop the source's decoration and branding.**
- **M: magnify the slot that carries the new idea best.**

Write each text to fit its slot's limit. Copy that's too long breaks the layout, and that only shows once it's rendered.

### 3. Drafts

- **A · Faithful:** the layout exactly as it is, the new content mapped directly.
- **B · Re-meant:** at least one metaphor given a stronger meaning, plus one demonstrating element.
- **C · Remixed:** one layout move the new topic earns.

### Worked example: "Marketing Funnel" → "How To Build A Reading Habit"

| Slot | Original | New | Letter |
|---|---|---|---|
| Title | The **Marketing** Funnel | How To Build A **Reading** Habit | S |
| Funnel bands | Awareness → Consideration → Conversion (narrowing) | Start → Stick → Love (widening: the habit grows) | S + R |
| Stage metric | Reach → Leads → Customers | 5 pages → 20 pages → a book a month | S |
| Side arrow | "Drop-off" | "Where people quit" + one fix | S + C |
| New element | — | A tiny reading log that fills up stage by stage | C + Magnify |
| Decoration | Logo strip, creator footer | Plain icons, "[Your Name]" footer | E |

## Reformat

The message is good; it needs to live somewhere new. Keep the core points, and change the format, the channel and usually the length.

1. **Extract the message spine.** One thesis, 3–7 key points, the best proof (a quote, an example, a number from the source), and the CTA. Never add claims the source doesn't make.
2. **Choose the three formats.** Use the user's choice if they gave one. Otherwise pick three that suit the audience, and say why in the Assess line. Common choices:
   - LinkedIn or Instagram carousel;
   - X or LinkedIn thread;
   - short video script (30–60 s);
   - newsletter section;
   - infographic;
   - quote cards;
   - podcast talking points.
3. **Adapt each format to how its channel works** (Adapt, not copy-paste):
   - **Carousel:** a hook slide, one idea per slide, a save-worthy final slide.
   - **Thread:** the first post must stand alone, one idea per post, end with the CTA.
   - **Video:** a hook in the first 2 s, spoken rhythm, on-screen text cues.
   - Limits for each are in `domains.md`.
4. **The drafts are the three formats.** Draft each as finished copy, in its structure (slide by slide, post by post, beat by beat). If a format is visual and a canvas is available, render the carousel cover and two slides, not the whole deck.
5. **Use SCAMPER inside each format:**
   - Magnify the strongest point into the hook;
   - Eliminate whatever the channel can't hold;
   - Reverse the order where the channel rewards it (lead with the conclusion).

## From a reference

The reference is a **direction**, not a container. The user wants something new that captures what they liked about it.

1. **Name what they liked**: the reference's mechanism. For example, "three parts feeding one result", "draws itself in", "hand-drawn warmth". This goes in Keep.
2. **Everything else is open:** layout, message, style details.
3. **Gather 2+ more references** (see `gather.md`), so the result isn't a variation of one source.
4. **The drafts:**
   - **at least two of the three get a structure different from the reference;**
   - A may stay close to the reference's layout, as the safe option;
   - B and C should each be a distinct visual idea that carries the kept mechanism.
5. **Originality check:** no draft could be mistaken for the reference with only the words changed.

## Fit checklist (all presets, before rendering and again at final)

- [ ] Every slot is filled; nothing is left over from the old topic.
- [ ] Every text fits its limit (bullets, characters, lines, platform limits).
- [ ] Every visual metaphor still *means* something for the new topic.
- [ ] Nothing of the source creator remains: name, handle, logo, photo, signature phrase. Footers become "[Your Name]".
- [ ] Unknown facts are [PLACEHOLDERS]; dates agree with the user's timeline.
- [ ] Contrast is at least 4.5:1; nothing is under 12 px at the published size.
