# Repurposing a template

The user has a structure they like (an infographic, carousel, post, slide, landing section, email) and wants it about a **new topic**. Usually they picked it for its layout, so by default you keep the skeleton and replace what's in it. The work is to understand *why* each part of the skeleton works and give it a new meaning that is just as strong.

## 1. Take a slot inventory

Before writing anything, list every slot in the source. Example: a "Marketing Funnel" infographic.

| Slot | Job it does | Limit | Carries a metaphor? |
|---|---|---|---|
| Title | Names the topic | ~3–5 words, 1–2 lines | No |
| Tagline | One-line promise | ~8 words | No |
| Funnel (3 stacked bands) | Shows stages from wide to narrow | 3 × 1–2 word labels | Yes: *narrows* top to bottom |
| Stage metric | The number that matters at each stage | ~10 characters | Yes: *shrinks* each stage |
| Tactic list per stage | What to do at this stage | 3 bullets, ≤6 words | No |
| Side arrow | "Drop-off" between stages | 2–3 words | Yes: loss |
| Tip box | One takeaway | ≤20 words | No |
| Footer | Creator CTA | 1 line | No |

Slots that carry a metaphor are where layout decisions happen. Everything else is content.

## 2. Decide what stays fixed

- **Default:** keep the layout exactly (the slots, their order, sizes and visual metaphors) and replace the content.
- **When the topic breaks a metaphor:** if a metaphor no longer holds (nothing "narrows" in the new topic), give it a new meaning, or swap that one piece. Either way, say so in the map.
- **Prompt overrides:**
  - "keep the layout exactly": never touch the layout;
  - "rework the layout too": run the full layout track, and make variation C a real layout change;
  - "content only": deliver the slot-by-slot copy as a table and skip rendering.

## 3. The content track

Run SCAMPER on the new topic's message, slot by slot. The strongest moves in a repurpose are usually these:

- **S: re-map each metaphor slot to a measure the new topic really has.** "Leads" becomes "pages read"; "drop-off" becomes "where people quit".
- **R: invert a metaphor when the new topic runs the other way.** A funnel that narrows can become one that *widens* when the new topic is about growing something.
- **C: add one demonstrating element** that makes the design prove its own point. For example, a tiny real example at each stage that grows or shrinks with the metaphor.
- **E: drop the source's decoration and branding** that has nothing to do with the new topic.
- **M: magnify the one slot that carries the new idea best.**

Then write the copy to fit each slot's limit. Count the bullets and roughly the characters. Too-long copy breaks the layout, and that only shows once it's rendered.

## 4. Fit check (before rendering)

- [ ] Every slot is filled, and no slot is left over from the old topic.
- [ ] Every text fits its limit (bullet count, characters, line count).
- [ ] Every metaphor still *means* something for the new topic. The reader can explain why it narrows, rises, fills or flows.
- [ ] Nothing of the source creator remains: no name, handle, logo, photo or signature phrase. Footers become a placeholder like "Follow [Your Name]…".
- [ ] Unknown facts are placeholders, never invented numbers.
- [ ] Colour and contrast still pass (text at least 4.5:1).

## 5. Variations for a repurpose

- **A · Faithful:** the layout exactly as it is, the new content mapped directly.
- **B · Re-meant:** the same layout, with at least one metaphor turned into a stronger meaning (a Reverse or Substitute on a metaphor slot), plus one demonstrating element.
- **C · Remixed:** a single layout move the new topic earns, such as flipping the funnel into a pyramid, swapping a meter for a different visual, or merging two panels.

Render them with `drafting.md`, then close with the "What changed" table. In a repurpose, its rows are the slots.

## Worked example: "Marketing Funnel" → "How To Build A Reading Habit"

| Slot | Original | New | Letter |
|---|---|---|---|
| Title | The **Marketing** Funnel | How To Build A **Reading** Habit | S |
| Tagline | Turn strangers into customers. | Turn "I should read more" into a daily habit. | S |
| Funnel bands (narrowing) | Awareness → Consideration → Conversion | Start → Stick → Love (bands *widen*, because the habit grows) | S + R |
| Stage metric | Reach → Leads → Customers | 5 pages → 20 pages → a book a month | S |
| Tactic lists | Ads, SEO, social… | Book on the pillow, phone in another room… | S |
| Side arrow | "Drop-off" | "Where people quit" + one fix per stage | S + C |
| New element | — | A tiny reading log that fills up at each stage | C + Magnify |
| Decoration | Logo strip, stock icons, creator footer | Plain icons, "[Your Name]" footer | E |
