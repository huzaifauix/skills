# Drafting posts

Turn a saved idea into a finished post the user can publish after a light edit.

## Each draft

1. Find the idea in `ideas.md` by ID or title. Write it for the platform the user names, or the first platform in `profile.md`.
2. Write in the voice from `profile.md`, following its **Avoid** list and **Preferences**.
3. Open with the saved hook, tightened if needed. The post delivers exactly what the title promises, on one idea.
4. Shape it to the format's **needs** line in `formats.md`: steps for a How to, the worst moment then the lesson for a Failure story, and so on.
5. Keep every ★ story, client result, quote and number as a bracketed placeholder (`[your client's name and result]`) unless `profile.md` records it. List the placeholders at the top of the draft so the user can fill them in quickly.
6. End with a call to action that fits the pillar: a question to start comments for Teach and Story posts, a soft pointer to the offer for Proof posts.
7. Save to `content-strategy/drafts/<ID>-<short-slug>.md` and set the idea's status to `drafted`.

Draft file layout:

```markdown
# <Title>
**ID:** I-007 · **Platform:** LinkedIn · **Pillar:** … · **Topic:** … · **Format:** …
**Fill in before posting:** [placeholder 1], [placeholder 2]

---

<post text>
```

When asked for several drafts at once, write every one in full. Show the first in the chat and list the file paths for the rest.

## Platform shapes

| Platform | Shape |
|---|---|
| **LinkedIn** | 150–300 words. Hook in the first 2 lines (before "see more"), short paragraphs of 1–2 lines, white space between them. 0–3 hashtags at the end. |
| **X / Threads** | A single post under 280 characters, or a thread of 5–8 posts where post 1 is the hook and each post stands on its own. |
| **Instagram carousel** | 6–10 slides: slide 1 is the hook as a headline, one point per slide in 25 words or fewer, final slide is the call to action. Add a 2–4 line caption. |
| **Instagram / TikTok video** | 30–60 second script: hook in the first 3 seconds, 3 beats, call to action. Include on-screen text cues. |
| **Newsletter** | 400–800 words with a subject line and preview text. Expand the idea with one example and one takeaway. |
| **Blog / article** | 800–1,500 words with H2 sections, written for the search phrase the topic implies. Suggest a meta description. |

If the user names another platform, follow its common conventions and say which you used.
