# Naming styles

Two-word pairs are where .com availability lives, but a list made only of `adjective+noun` reads as generic. Mix several styles below so the shortlist has range, then let availability and the user's taste decide. Aim for at least four styles in each batch.

| Style | How to build it | Examples (real brands, for the pattern only) | Availability |
|---|---|---|---|
| Compound | modifier + core, or core + modifier | Mailchimp, Dropbox, Basecamp | good when one word is unexpected |
| Unexpected pairing | core word + an unrelated concrete noun (object, animal, place) | Squarespace, Monkey Mail, Red Bull | good; the oddness makes it memorable |
| Blend (portmanteau) | overlap the end of one word with the start of another | Pinterest (pin+interest), Instagram, Groupon | good; check it still reads both words |
| Truncation | cut a word and add a crisp ending | Tumblr, Flickr, Spotify | weak for one word, good with a second word |
| Suffix/prefix | root + -ly, -ify, -io, -ster, -hub, -lab, -kit; or get-, try-, use-, go- | Calendly, Shopify, GetResponse | fair; prefixes are a fallback for a taken .com |
| Invented | 2–3 syllables built from sounds that suit the feel (hard k/t = technical, soft l/m/v = calm, z/x = energetic) | Zillow, Hulu, Kodak | mixed; short ones are mostly taken |
| Metaphor | a real word from a neighbouring world that hints at the benefit | Amazon (scale), Slack, Stripe | poor alone; good paired with a core word |
| Alliteration / rhyme | two words sharing a first sound or a rhyme | Coca-Cola, PayPal, Dunkin' Donuts | good; very sayable |
| Persona / host | a name, title or character | Mr Beast, Dollar Shave Club, Ask Dave | good for channels |
| Misspelling | drop a vowel, swap c/k, ph/f | Lyft, Flickr, Krispy | fair; costs spelling-on-the-phone clarity |

## Quality filters (apply to every style)

- **Radio test:** someone hearing it once can type it. Fail misspellings that need explaining.
- **Mouth feel:** 2–3 syllables, no consonant pile-ups at the join (`stackstrong`).
- **Meaning check:** no unfortunate words hiding at the join (`therapist` → `the rapist`), and no bad meaning in other big languages for the audience.
- **Niche fit:** the name hints at the niche *or* the feel, ideally both, without being a dictionary description of it (`BestWebHosting` is clear but forgettable).
- **Growth room:** avoid locking to a narrow product if the brief says the brand may grow.
